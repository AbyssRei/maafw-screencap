# 来源、生命周期与代次契约设计

日期：2026-10-27。状态：设计约束已确认，产品实现与验收待完成；具体公共 SDK 类型、签名、状态编码与生成工具仍在 P2 验收后的 P3 定案。

阶段边界和验收门禁以[实施计划](../plans/maafw-screencap-extraction-plan.md)为准。本文未标明文件的“第 N 节”均指该计划的对应章节；计划保留原章节号并链接详细规则。U/P 继续保持固定上游行为，本文产品设计不提前进入 P0/P1/P2。

## 来源快照与布局依赖

区分稳定来源 key、枚举快照内容指纹、目标几何代次和原生捕获资源代次。
快照指纹用于规定范围内的一致性比较，不承诺跨进程持久、单调递增或无碰撞的身份语义。
后端声明所依赖的输出/适配器/布局；目标几何或实际依赖变化时拒收并使相应资源失效。
非目标显示器变化、名称变化是否影响当前捕获按依赖判断，不一律等同目标身份变化，也不能漏掉共享设备失效。
枚举重试纳入操作预算；热插拔、镜像/克隆及重排期间无法形成一致快照时返回布局错误，不回退到另一个来源。

## 全虚拟桌面目标

该目标作为 P3 产品扩展纳入规划，首个匹配方法为 Windows 独立 GDI 全虚拟桌面方式，尚未实现或验收。它表示连接时绑定的当前可访问桌面及其活动逻辑显示区域集合，不是窗口句柄为空、主显示器或任意显示器索引的别名；不承诺跨交互桌面或会话的持久身份。

本次操作固定来源集合、桌面原点、覆盖区域与相关布局证据，并在发布前复验。热插拔、重排、旋转、像素映射或桌面来源变化使相关缓存和资源失效，本次结果拒收；首期需显式重连以接受新布局，不在普通捕获中静默扩大或缩小来源集合。P4 自动恢复如开放，须显式协商接受新布局的规则并报告新代次。

前后查询不能证明捕获期间布局从未变化，保留非原子观察的限制。不能确定活动区域、镜像关系或坐标映射时报告不支持或布局错误，不退回主屏。此规则不改变单显示器目标仅按其实际布局依赖失效的契约；像素及覆盖信息见[全虚拟桌面帧](frame.md#全虚拟桌面帧)。

## 生命周期操作

| 操作 | 语义 |
| --- | --- |
| connect/open | 建立或验证会话；正式首样本可保留，交付前复验 |
| pause/resume | 停止/恢复 producer 或取样；保留哪些原生会话和有效样本按后端声明 |
| release resources | 释放捕获资源，使 pending/cache 和相关会话代次失效；后续捕获按明确路径重建 |
| close/destroy | 终结对象、停止事件入口、安全退出、恢复本库临时状态并释放所拥有资源 |
| get state | 快速读取逻辑状态 |
| probe source | 如提供，显式执行来源验证并说明系统查询成本 |

来源身份、原生会话、格式与窗口修改各有独立代次，按对应事件推进。
格式重协商时废弃不再适用的缓存和 pending 帧；晚到结果不能重新写入已失效代次。
已交付 Frame 保持其像素和描述，暂停后的回放仍受来源、格式、时间与策略约束。

外部 fd、Wayland 连接和平台句柄逐项定义借用、复制或转移，以及创建失败、重试和关闭的归属。
默认优先取得可独立拥有的副本；不可复制资源使用显式转移入口。
授权资源消费后若无法重用，重建需要新的有效授权；失败路径保持原目标与授权边界。
本库创建或复制的 fd 默认设置 close-on-exec；借用 fd 的宿主属性按契约保留。

复制描述符只隔离关闭责任，不创建新的底层协议连接；`dup` 的共享对象语义依据 [Linux 手册](https://man7.org/linux/man-pages/man2/dup.2.html)。
同一协议 socket 不能仅靠复制 fd 就交给多个独立客户端，也不据此承诺授权资源可重复建连。
在约定的接管点复制或转移资源，不在延后的首次捕获中重新按宿主可能已经关闭/复用的 fd 数值取源。
每个原生创建接口分别确认成功和失败是否消费输入，不能统一假设“仅成功时移交”；资源消费状态在调用点更新，回滚不得再次释放已被消费的输入。

## 失败后的状态与恢复

阶段三为每类原生结果定义返回值、Session 状态、缓存处理和下一次允许的操作，不能仅用 `connected` 布尔值代表资源仍有效。

| 结果或事件 | 状态与恢复要求 |
| --- | --- |
| 无更新/等待超时 | 与断连区分；只在样本仍有效且策略允许时回放，不仅凭超时次数或像素不变判定来源死亡 |
| 设备丢失/捕获访问失效 | 废弃相关缓存、pending 和原生资源，推进代次；声明下次捕获可重建还是必须显式重连 |
| 权限撤销/授权会话结束 | 停止交付并使授权关联状态失效；仅在取得新授权后恢复，不隐式弹出授权 UI |
| 目标销毁/身份变化/输出移除 | 终止对原对象的采样及修改，不按旧索引、主屏或复用的原生句柄选择替代目标 |
| 取消/期限耗尽/恢复失败 | 拒收本次结果，报告资源已释放、仍在途或待恢复；明确会话后续可用性，保留独立 Frame |

P3 先实现可观察的失败状态和显式恢复路径；自动重建、重连或 Auto 重新选法作为 P4 策略，默认值由 ADR 冻结。
自动恢复限定次数、退避和总预算，取消后停止重试；即使重新选法也保持原目标和必需的画面/副作用约束。
上游已有重试、回放和连续超时阈值在 U/P 保持原语义，不能提前改成此表中的产品行为。

## 状态转换的实施记录

P3 为每个操作/事件记录前置逻辑状态、原生资源状态、结果状态、推进的代次、缓存/pending 处理、清理责任和下一次允许的操作。以下只规定关系，不提前冻结状态枚举和 ABI 数值：

| 操作/事件 | 必须明确的转换 |
| --- | --- |
| connect/open | 成功取得可用资源；部分初始化失败回滚，正式首样本仍经同一发布检查 |
| pause/resume | 逻辑暂停与资源保留分开；恢复是否需要 producer 操作由后端声明 |
| release resources | 资源、pending/cache 和相关代次失效；已交付 Frame 独立有效 |
| close/destroy | 禁止与活动宿主调用竞争；终结与窗口恢复结果可观察，不遗失待恢复责任 |
| 格式/设备/来源变化 | 分别推进对应代次，晚到结果不得恢复已失效状态 |
| 取消/超时 | 本次操作终结与系统请求仍在途分开；额度及资源责任保留到真正完成 |

身份、几何、格式、设备/会话和窗口租约使用区分种类的内部 token；快照指纹不充当可互换的代次计数器。后端报告原生失效证据，会话执行统一失效与发布决策，具体状态拥有者见[架构设计](../design/architecture.md)。
